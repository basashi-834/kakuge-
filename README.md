# Kakuge — 2D 対戦格闘ゲーム（C++17 + SDL2）

1990 年代のアーケード格闘ゲームを手本にした、2D 対戦格闘ゲームです。
384x224 という当時のアーケード基板と同じ内部解像度で描画し、
それを画面いっぱいに整数倍で拡大して表示しています。

**ビルドの手順は [BUILD_WINDOWS.md](BUILD_WINDOWS.md) を見てください。**
はじめての方向けに、1 コマンドずつ丁寧に書いてあります。

---

## 決めごと

| 項目 | 内容 |
|---|---|
| 言語 | C++17 |
| ライブラリ | **SDL2 のみ**（2.0.18 以降。`SDL_RenderGeometry` を使用） |
| ビルド環境 | Windows + Visual Studio（MSVC / CMake）。SDL2 は直接DL または vcpkg |
| コメント | 初心者向けに日本語で厚めに |

SDL2 以外のライブラリは一切使いません。そのため、
本来なら外部ライブラリに頼る次の 2 つは自前で用意しています。

- **JSON の読み書き** → `src/core/Json.cpp`（約 400 行の自前パーサ）
- **文字の表示** → `src/platform/Font.cpp`（手描きの 5x7 ドットフォント）

---

## 実装している内容

**戦闘システム**

- フレーム単位の技データ（発生 / 持続 / 硬直）
- 3 種類の当たり判定（攻撃・食らい・押し合い）を厳密に分離
- 食らい判定は頭・胴・脚の 3 部位に分割（姿勢ごとに形が変わる）
- ガードの種類（上段 / 下段 / 中段 / 投げ）
- のけぞり・ガード硬直・ヒットストップ・ダウン・起き上がり
- キャンセル（コンボ）、カウンターヒット 2 段階
- 超必殺技ゲージ、飛び道具、投げ（距離判定）
- 入力バッファとコマンド技の認識（236 / 623 / 214 / 236236 など）
- 押し合い判定の解決（画面端では端側が動かない）

**画面**

- タイトル / キャラクター選択 / 対戦前演出 / 対戦 / 結果 / 設定 / 操作説明
- 自動ズームカメラ（2 人の距離に応じて寄り引き、ステージ外は映さない）
- ポーズメニュー、トレーニングモード（自動回復・練習相手の姿勢固定）
- 当たり判定の可視化（トレーニング中に `F1`）

**CPU 対戦相手**

人間とまったく同じ入力しか行いません（内部で特別扱いをしていません）。
間合いに応じて、接近・攻撃・ガード・対空・飛び道具を選びます。

## フォルダ構成

```
CMakeLists.txt        ビルドの設定（これを CMake に読ませます）
BUILD_WINDOWS.md      ビルド手順書
data/                 キャラクターと技のデータ（JSON）
src/
  main.cpp            起動
  core/Json.*         自前の JSON 読み書き
  engine/             戦闘のルール（SDL2 に一切依存しない）
    Constants.h         共通の定数と寸法の基準
    Boxes.h             当たり判定の四角形
    CharacterStats.h    キャラクターの基本性能
    MoveData.h          技 1 つぶんのデータ
    MoveExecutor.h      技が今どの段階かの計算
    StateMachine.h      状態の管理
    InputSystem.h       入力履歴とコマンド認識
    Fighter.h           キャラクターの本体（一番大きい）
    CPUAI.h             CPU の思考
    BattleSystem.h      試合の進行役
    Projectile.h        飛び道具
    SuperGauge.h        超必ゲージ
    DataManager.h       データの読み書き
    Settings.h          画面設定
  platform/           SDL2 を使う部分（画面と入力）
    Renderer.*          描画の土台（SDL_RenderGeometry）
    Font.*              ドットフォント
    Figure.*            キャラクターの絵
    Camera.*            カメラと座標変換
    Hud.*               体力ゲージなどの情報表示
    Game.*              メインループと画面の切り替え
    Screens.cpp         各画面の見た目
    Paths.*             フォルダの場所
    Palette.h           配色
tests/EngineTests.cpp  エンジンの自動テスト（68 項目）
legacy-win32-gdiplus/  旧版（Win32 + GDI+）。参考用に残しています
```

`engine/` は SDL2 も Windows も一切使っていません。
だから画面を出さずにテストでき、将来ほかの環境へ移すのも簡単です。

## データを書き換えて遊ぶ

技の性能はすべて `data/moves/ryu/*.json` に入っています。
プログラムを触らずに、テキストエディタでこれを書き換えるだけで調整できます。

```json
{
  "id": "standing_heavy",
  "name": "立ち強パンチ",
  "startup": 7,          ← 発生（ボタンを押してから当たるまでのフレーム数）
  "active": 3,           ← 持続（攻撃判定が出ている長さ）
  "recovery": 13,        ← 硬直（動けない時間）
  "damage": 120,
  "hitbox": [{ "offsetX": 26, "offsetY": -61, "width": 20, "height": 12 }]
}
```

書き換えたら `data` フォルダを `build\bin\data` にコピーし直す
（またはビルドし直す）だけで反映されます。

キャラクターの性能は `data/characters/ryu.json` です。

> ゲーム内で編集した内容や画面設定は、ゲーム本体のフォルダではなく
> `%APPDATA%\Kakuge\` に保存されます。元のデータは書き換わりません。

## 旧版について

`legacy-win32-gdiplus/` に、SDL2 化する前の Win32 + GDI+ 版が入っています。
キャラクターエディタ（技の数値をゲーム内で編集する画面）はそちらにあり、
SDL2 版にはまだ移していません。技の調整は今のところ JSON を直接
書き換えて行ってください。
